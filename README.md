**Конвертація документів Word (.docx) у PDF на чистому Go.** Без cgo, LibreOffice
чи headless-браузера: програма збирається в один бінарник і нічого не запускає поруч.

- Кирилиця з коробки: шрифти вбудовано, тож відкритий PDF не покаже «кракозябр».
- Розмітка близька до Word: табуляція, межі абзаців, розрідження, таблиці, колонтитули, виноски.
- Підходить для сервісів: читає з пам'яті, пише в `io.Writer`, вхідний .docx
  вважається недовіреним.
- Відтворюваний вихід: однаковий .docx дає однакові байти PDF.

Мета — читабельний документ, що збігається з Word за розміткою рядків і сторінок,
а не піксель у піксель.

## Встановлення

```sh
go get github.com/h0rn3t/docx2pdf@latest
```

Потрібен Go 1.27 або новіший.

## Швидкий старт

### З файлу у файл

```go
import "github.com/h0rn3t/docx2pdf/document"

doc, err := document.Open("заява.docx")
if err != nil {
	log.Fatal(err)
}
defer doc.Close()

if err := doc.WritePDF("заява.pdf"); err != nil {
	log.Fatal(err)
}
```

### З пам'яті в будь-який `io.Writer`

Зручно в HTTP-обробнику чи черзі, де .docx уже лежить у `[]byte`:

```go
doc, err := document.OpenReader(bytes.NewReader(data), int64(len(data)))
if errors.Is(err, document.ErrTooLarge) {
	// файл понад 64 МіБ — відхилити, наприклад, з 413
}
if err != nil {
	return err
}
return doc.WritePDFTo(w)
```

### Налаштування конвертації

`ConvertToPdf` повертає `Converter`, налаштування якого можна поєднувати:

```go
err = document.ConvertToPdf(doc).
	WithSystemFonts().              // шрифти ОС, як у Word, замість вбудованих замінників
	WithCreationDate(signedAt).     // фіксована дата — однакові байти для однакового .docx
	Write(w)
```

| Метод | Що робить |
|---|---|
| `WithSystemFonts(dirs...)` | Малює текст шрифтами, встановленими в ОС. Без аргументів шукає у стандартних теках системи й користувача. Вихід тоді залежить від машини. |
| `WithCreationDate(t)` | Записує `t` як дату створення й зміни PDF. Потрібно для тестів з еталонним PDF. |
| `Write(w)` / `WriteToFile(path)` | Рендерить документ і пише PDF. |

## Командний рядок

Готовий приклад лежить у [`examples/docx2pdf`](examples/docx2pdf):

```sh
go run ./examples/docx2pdf [-system-fonts] in.docx out.pdf
```

## Що підтримується

<details open>
<summary><b>Текст</b></summary>

- жирний, курсив, підкреслення, закреслення, гарнітура, розмір;
- колір, зокрема кольори теми; заливка й виділення маркером;
- верхні й нижні індекси, усі великі та малі великі літери;
- міжлітерний інтервал (`w:spacing`), як у заголовках «З А Я В А»;
- прихований текст (`w:vanish`) у PDF не потрапляє.

</details>

<details open>
<summary><b>Абзаци</b></summary>

- вирівнювання, зокрема за шириною; відступи, червоний рядок і виступ;
- інтервали до й після, міжрядковий, `contextualSpacing` між абзацами одного стилю.
  Розмітка рядків як у Word і LibreOffice: висота рядка з метрик шрифту (`hhea`/`OS/2`)
  з округленням до твіпа, сусідні інтервали «після» й «перед» не додаються, а береться
  більший, інтервал «перед» на початку сторінки (крім першої) відкидається;
- табуляція: ліва, права, по центру, десяткова й вертикальна риска, із заповнювачем;
  стоп за правим полем, як у Word, виводить текст на поле замість переносу;
- межі абзацу (`w:pBdr`): верхня, нижня, ліва, права й між абзацами, одинарні й
  подвійні, з відступом від тексту. Сусідні абзаци з однаковими межами Word
  об'єднує в одну рамку, і тут так само;
- перенос після дефіса всередині слова («інженеру-|програмісту»);
- `keepNext` і `keepLines` враховуються під час розбивки на сторінки;
- стилі абзаців і символів зі `styles.xml` разом із ланцюжком `basedOn`; абзац без
  стилю отримує стиль за замовчуванням (`w:default="1"`, зазвичай «Звичайний»).

</details>

<details>
<summary><b>Списки й символи</b></summary>

- нумеровані, марковані й картинкові маркери з `numbering.xml`;
- `w:sym` і маркери у шрифтах Symbol та Wingdings. Якщо самого шрифту немає, їх
  замінюють Unicode-символи: •, ▪, □, √, грецькі літери тощо.

</details>

<details>
<summary><b>Таблиці</b></summary>

- об'єднання комірок, рамки, заливка, стилі таблиць;
- вирівнювання таблиці по центру й праворуч, автопідбір ширин колонок;
- вертикальний текст, вкладені й плаваючі таблиці;
- повторювані рядки заголовка; рядок, що не вміщується, розривається між сторінками
  по межі рядка тексту, якщо не позначений `w:cantSplit`;
- таблиця винесена вліво на поле комірки, як у Word, вкладена стискається до своєї комірки.

</details>

<details>
<summary><b>Сторінки</b></summary>

- секції з власним розміром, орієнтацією й полями;
- колонки з балансуванням;
- колонтитули, окремі для першої та парних сторінок;
- поля `PAGE` і `NUMPAGES` з точною кількістю сторінок;
- звичайні виноски внизу сторінки, кінцеві — після тексту.

</details>

<details>
<summary><b>Зображення, поля й посилання</b></summary>

- PNG, JPEG, GIF, TIFF, BMP, WebP; SVG — через PNG-копію, яку зберігає Word;
- обрізка, базові ефекти, плаваючі рисунки з обтіканням текстом;
- текстові поля (`wps:txbx`, VML `v:textbox`, зокрема в `mc:AlternateContent`) з рамкою,
  заливкою, внутрішніми відступами, вертикальним вирівнюванням і підгонкою під текст:
  у рядку або плаваючі на своїй позиції, поверх тексту чи з обтіканням; так само
  прямокутники VML і DrawingML;
- клікабельні гіперпосилання й переходи до закладок.

</details>

<details>
<summary><b>Формули</b></summary>

- OMML (`m:oMath`) у тексті й окремим рядком (`m:oMathPara`, по центру або за `m:jc`);
- дроби, корені зі степенем, верхні й нижні індекси (зокрема ліві), дужки будь-якої
  висоти з роздільниками, суми й інтеграли з межами, функції, `lim`, акценти,
  риска над і під виразом, рамка, фігурна дужка над і під виразом, матриці,
  системи рівнянь, фантоми;
- змінні курсивом, числа й оператори прямим, відступи навколо операторів як у Word.

</details>

<details>
<summary><b>Шрифти</b></summary>

- кирилиця й Unicode через вбудовані метрично-сумісні шрифти: Calibri → Carlito,
  Arial, Times New Roman, Courier New → Liberation;
- шрифти, вбудовані в .docx, використовуються завжди, системні — з `WithSystemFonts()`;
- у PDF потрапляють лише ті накреслення, якими справді написано текст, і лише
  потрібні символи. Через це PDF виходить компактним: сторінка заяви займає ~40 КБ.

</details>

## Обмеження

Непідтримуваний вміст пропускається, а конвертація все одно завершується успішно.

| Що | Як поводиться |
|---|---|
| Поля, крім `PAGE`/`NUMPAGES` | Показують кешований результат із документа. |
| EMF/WMF без растрової копії, фігури (крім прямокутників і текстових полів), діаграми, прозорість | Не показуються. |
| Групи фігур (`v:group`, `wpg:wgp`) | Текст їхніх полів іде в потоці після абзацу-якоря, без рамки й позиції. |
| Формули | Набираються вбудованим serif-шрифтом замість Cambria Math; високі дужки й корені малюються лініями. Вирівнювання рядків системи за `&` не враховується. |
| Позначений чекбокс Wingdings (☑, ☒) без шрифту | Малюється заповненим квадратом ■. |
| `keepNext`, `keepLines` | Діють лише в основному тексті, не в комірках і колонтитулах. |
| Висячі рядки (`widowControl`) | Не контролюються. |
| Межі абзацу в комірках таблиць | Не малюються. Подвійна межа таблиці — однією лінією. |
| Підкреслення розрідженого тексту | Трохи коротше за сам текст. |
| Обтікання плаваючих об'єктів | Лише з ширшого боку. У комірках таблиць об'єкти стоять у рядку. |
| Виноски | У багатоколонковій секції займають усю ширину. Не переносяться на наступну сторінку, нумерація не перезапускається. |
| Балансування колонок | Лише для колонок, що вміщуються на поточну сторінку. |
| Шрифти без вбудованої чи системної версії | Замінюються, тож переноси можуть трохи відрізнятися від Word. `.otf` з CFF-контурами й `.ttc` не використовуються. |
| Не підтримуються | Примітки (коментарі), масштаб тексту, автоматичні переноси (крім розриву після дефіса), письмо справа наліво й складні писемності (арабська, іврит, індійські), PDF/A. |

## Безпека

Вхідний .docx вважається недовіреним:

- `OpenReader` не читає файл понад 64 МіБ і повертає `ErrTooLarge`;
- кожна розпакована частина ZIP — до 256 МіБ, декодоване зображення — до 50 Мпікс;
- `w:gridSpan` обмежено 63 колонками, `w:cols` — 45;
- вбудовані шрифти перевіряються перед використанням, тож зламаний шрифт не валить конвертацію;
- клікабельні лише посилання `http`, `https`, `mailto`, `ftp`, `tel`.
