# docx2pdf

Бібліотека на чистому Go для конвертації документів Word (.docx) у PDF — без cgo,
LibreOffice чи headless-браузера.

```sh
go get github.com/h0rn3t/docx2pdf@v0.0.8
```

## Використання

```go
doc, err := document.Open("in.docx")
if err != nil {
	log.Fatal(err)
}
defer doc.Close()

if err := doc.WritePDF("out.pdf"); err != nil {
	log.Fatal(err)
}
```

Щоб текст малювався шрифтами, встановленими в ОС (як у Word), а не метрично-сумісними
замінами:

```go
err = document.ConvertToPdf(doc).WithSystemFonts().WriteToFile("out.pdf")
```

Готовий приклад — [`examples/docx2pdf`](examples/docx2pdf):

```sh
go run ./examples/docx2pdf [-system-fonts] in.docx out.pdf
```

## Що підтримується

Мета — читабельний, «пливкий» текст документа, а не піксель-у-піксель копія Word.

- **Текст:** жирний, курсив, підкреслення, закреслення, гарнітура, розмір, колір
  (зокрема кольори теми), індекси, заливка й виділення, усі великі й малі великі
  літери. Прихований текст (`w:vanish`) у PDF не потрапляє.
- **Абзаци:** вирівнювання, відступи, інтервали (зокрема `contextualSpacing` між
  абзацами одного стилю), розриви та табуляція (зокрема decimal і bar) зі стилями
  `styles.xml` і шрифтами теми. «Не відривати від наступного» та «не розривати
  абзац» (`keepNext`, `keepLines`) враховуються під час розбивки на сторінки.
- **Списки:** нумеровані, марковані й картинкові маркери з `numbering.xml`.
- **Символи:** `w:sym` і маркери у шрифтах Symbol та Wingdings. Якщо самого шрифту
  немає, вони малюються Unicode-замінниками: •, ▪, □, √, грецькі літери тощо.
- **Текстові поля:** текст із `wps:txbx` і VML `v:textbox` (зокрема всередині
  `mc:AlternateContent`) виводиться після абзацу, до якого прив'язане поле.
- **Поля й посилання:** `PAGE` і `NUMPAGES` з точною кількістю сторінок,
  клікабельні гіперпосилання й переходи до закладок.
- **Виноски:** звичайні внизу сторінки, кінцеві — після тексту.
- **Сторінки:** секції з власним розміром і полями, колонки з балансуванням,
  колонтитули першої та парних сторінок.
- **Зображення:** PNG, JPEG, GIF, TIFF, BMP, WebP (SVG — через PNG-копію Word),
  обрізка, базові ефекти, плаваючі рисунки з обтіканням текстом.
- **Таблиці:** об'єднання комірок, рамки, заливка, стилі таблиць, вирівнювання
  по центру й праворуч, автопідбір ширин, вертикальний текст, вкладені й плаваючі таблиці, повторювані заголовки
  та посторінкова розбивка.
- **Шрифти:** Unicode і кирилиця через метрично-сумісні заміни (Calibri →
  Carlito, Arial/Times/Courier → Liberation). Шрифти, вбудовані в .docx,
  використовуються завжди, системні — з `WithSystemFonts()`.

## Безпека

.docx вважається недовіреним входом:

- кожна розпакована частина ZIP — до 256 МіБ, а декодоване зображення — до 50 Мпікс;
- `w:gridSpan` обмежено 63 колонками, а `w:cols` — 45;
- вбудовані шрифти перевіряються перед використанням, тож зламаний шрифт не валить
  конвертацію;
- клікабельні лише посилання `http`, `https`, `mailto`, `ftp`, `tel`.

## Обмеження

Непідтримуваний вміст пропускається, а конвертація все одно завершується успішно.

- Поля, крім `PAGE`/`NUMPAGES`, показують кешований результат.
- EMF/WMF без растрової копії не показуються, як і прозорість, фігури, діаграми
  та графіки. Текстові поля не мають власної рамки й позиції: їхній текст іде
  в потоці після абзацу-якоря.
- Позначений чекбокс Wingdings (☑, ☒) без самого шрифту малюється заповненим
  квадратом ■.
- Текст обтікає лише ширший бік об'єкта. Плаваючі об'єкти в комірках таблиць
  стоять у рядку.
- У багатоколонковій секції виноски займають всю ширину сторінки. Виноска не
  продовжується на наступній сторінці, а нумерація не перезапускається.
- Балансуються лише колонки, що вміщуються на поточну сторінку.
- Шрифти без вбудованої чи системної версії замінюються, тож переноси можуть трохи
  відрізнятися від Word. `.otf` з CFF-контурами і `.ttc` не використовуються.
